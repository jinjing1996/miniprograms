睡前故事 · 可点击原型

四条链路都能走通：讲故事 → 生成中 → 播放 → 我的。纯前端模拟，没有真音频，逐句高亮由内置时间轴驱动。

怎么试 建议顺序

  • ① 点一个主题 chip（会填进输入框，可再改两个字）
  • ② 参数随点随生效 → 按「生成故事」
  • ③ 生成中：段落逐段淡入、进度文案按阶段变、插图计数在跑
  • ④ 就绪后落在播放页，必须点那枚大播放键才起播
  • ⑤ 起播后试：点任意句 seek、左右横滑翻段、拖进度条、切语速、切定时
  • ⑥ 播完停在「晚安」，不自动连播
  • ⑦ 「我的」→ 打开深色更暗，睡前暗光观感在这里看
  • ⑧ 输入「打屁股」或「鬼」试试被拦：文案不含糊，次数不扣

原型里能直接看到的三处合规

  • 待点起播：落地不自动播（拒绝情形 3.5.2「禁止视频、音乐、语音等多媒体的自动播放」）
  • AIGC 常驻标识：播放页副标题下「内容由AI生成…」，含「AI生成」四字原样，不可折叠
  • 文案禁词：全界面不出现「绘本 / 读物 / 听书 / 电台 / 节目 / 课程」（禁词表见 docs/页面与交互.md）

与真实实现的差异

  • 插图是内联 SVG 占位，真实为 Seedream 生成 + 参考图角色一致性
  • 时长/句时间戳是写死的演示数据；真实来自 TTS 字级时间戳派生（docs/接口与数据.md §3）
  • 切语速在原型里只改走时；真实要后端重合成并取新的时间戳
  • 额度、收藏、历史只在内存里，刷新即重置
