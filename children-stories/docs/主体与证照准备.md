# 主体与证照准备

面向动作：**注册一个能上架 AIGC 儿童故事小程序、能收款的个体工商户**，并知道什么时候必须升级成公司。

除标注「未找到官方依据」外，本节结论均有官方原文，出处见 §6。

## 1. 主体类型判定

| 能力 | 个人主体 | **个体工商户** | 有限公司 | 依据 |
|------|---------|---------------|---------|------|
| 微信小程序「深度合成」类目 | ❌ 不可选（个人分区无此类目） | ✅ | ✅ | 官方类目页只分「个人 / 非个人」两区，**未区分企业与个体户** |
| 微信支付普通商户号 | ❌（无执照只能走小微/个人卖家，需服务商接入） | ✅ 进件主体枚举含「4：个体工商户」 | ✅ | 商户开户文档 |
| 收款结算账户 | — | ✅ **可用经营者对私账户**（74-对公 / 75-对私） | 一般需对公 | 同上 |
| 微信认证（300 元） | ❌ 原文「个人不可认证」 | ✅ | ✅ | 认证指引 |
| 手机号快速验证接口 | ❌ | ✅（需非个人主体 + 已完成认证；0.04 元/次） | ✅ | 接口文档 |
| URL Scheme / URL Link 拉起 | ❌ | ✅ | ✅ | 同上 |
| 小程序直播 | ❌ | ✅ | ✅ | 直播准入条件 |
| 成员（开发者）上限 | 15 | **90**（已认证已发布非个人） | 90 | 成员管理文档 |
| **同一主体可注册小程序数** | **5** | **5**（和个人一样） | **50** | 注册上限原文 |
| 增值电信（ICP 经营）/文网文等许可 | ❌ | ❌ **法律上拿不到**：许可须为依法设立的公司，省内经营注册资本 ≥100 万 | ✅ | 《电信业务经营许可管理办法》第六条 → 见 §2 触发点 |

**结论**：这个项目**先注册个体工商户**。个人主体是死路（选不到必需类目、不能收款、不能认证）；公司主体在你现在这个阶段只多付成本，不多给能力。

⚠️ **但这句话要说限定条件**（本轮核实新增）：「个体户够用」这个结论**成立的范围是文本 + 图片**。我们的**朗读音频在类目表里找不到对应子项**（深度合成 5 项只覆盖 情感互动/文本/视频/图片/文本），一旦被要求补「文娱-电台/有声读物」，那些证的门槛是「**具备法人资格**」（视听证再加国有控股）——**这种情况下换公司也不解决问题**，只是换一种死法。所以正确表述是：**个体户不会成为文本与图片的障碍；音频能否上架，取决于 §8 第 1 通电话的答复，而不是主体类型。**

**注册上限 5 个这条要知道**：同一个体户的营业执照最多注册 5 个小程序，和身份证注册的 5 个是两套额度。将来小程序矩阵超过 5 个才需要考虑公司主体。

## 2. 必须升级成公司的三个触发点（第三个连升级都不够）

1. 火山（或 LLM 供应商）**拒绝以个体工商户抬头出具**符合要素的合作协议（算法名称 / 应用场景 / 备案编号）。官方资质要求本身**没有**规定对方或我方必须是企业，这是商务政策而非规则，**一个电话就能确认**，注册前先问。
2. 要做 toB（开专票、投标、机构合同）、或需要 ICP 经营许可证 / 网络文化经营许可 / 广播电视节目制作经营许可。
   **这一条不是「更体面」，是法律硬限制**：《电信业务经营许可管理办法》第六条要求「经营者为依法设立**的公司**」，省内经营「注册资本最低限额 **100 万元**」→ **个体工商户拿不到增值电信许可**。所以第二版订阅收费若被属地通管局或主管部门认定为经营性互联网信息服务需 B25 许可，路径只能是**先新设公司再申请**，个体户这张照改不出许可。
   （注：此认定本身有解释空间，微信侧文档把「ICP 备案**或**增值电信许可」列为二选一，见 §7 末；不要为了这个不确定性提前变更经营范围，理由见 §3 末尾。）

处理方式：新设公司，两个主体并存，小程序做主体迁移或新开，个体户按需注销。**不必推倒重来。**

**第三个触发点（形态相关，不是收费相关）**：做**真 AI 视频生成**，或**被审核要求把朗读音频补挂文娱类目**。`深度合成 - AI创作` 的适用范围原文只覆盖**文本**深度合成技术，语音与视频都没有对应子项；视频形态很可能被要求补「文娱-其他视频」（前置审批 6 选 1）或「视频广场」（明确要求**企业主体** + 视听节目备案），音频形态可能被要求补「文娱-电台」或「文娱-有声读物」。

这几张证卡死个体户的只有一条：**不具备法人资格**。

| 证照 | 卡点原文 | 出处 |
|------|---------|------|
| 《信息网络传播视听节目许可证》 | 第八条：申请应当**同时**具备「（一）**具备法人资格，为国有独资或国有控股单位**，且在申请之日前三年内无违法违规记录」 | 56 号令（广电总局/信产部令第 56 号）第二条、第七条、第八条；总局《许可证审批事项服务指南》七(一)1 同口径 |
| 《广播电视节目制作经营许可证》 | 第六条：「（一）**具有独立法人资格**」 | 《广播电视节目制作经营管理规定》（广电总局令第 34 号）。⚠️ 第二条把「**广播剧**」明文列为覆盖的节目类型 → **纯音频也在射程内** |
| 《网络出版服务许可证》 | 第七条须经出版行政主管部门批准；第九条要求除法定代表人和主要负责人外有 **8 名以上**专职编辑出版人员（中级以上资格不少于 3 名） | 《网络出版服务管理规定》第二条、第七条、第九条。⚠️ 第二条(一) 的定义明文含「**音视频读物**」 |
| 《网络文化经营许可证》 | 须省级文化行政部门批准 | 《互联网文化管理暂行规定》第八条 |

→ **个体工商户不具备法人资格，上述四张一张都申请不了**；视听证另加「国有独资或国有控股」，所以**连民营公司也过不去**。换句话说：换成普通公司只可能解开文网文与制作经营许可证这两张，解不开视听证。

⚠️ **两处我此前写错、现已按原文修正（留记录，别沿用旧结论）**：

1. ~~「注册资本 1000/2000 万以上」是许可门槛~~ → 该数字出自**广发〔2008〕44 号通知**（申办企业注册资本 1000 万以上；提供新闻、影视剧、文娱、专业等多种内容 2000 万以上），属**规范性文件的审查口径**；2018 年总局《许可证审批事项服务指南》的申请条件里**已不列注册资本**，只保留「专业人员数量应在 **20 人以上**」。**不要把注册资本当法规门槛。**
2. ~~「分类目录分三类，国有控股只约束第一类」~~ → 2017 年调整后目录是**四类**（一：广播电台电视台形态服务；二：专业类视听节目的**制作、播出**与汇集；三：聚合与转发网民上传；四：转播），但**目录本身不设任何许可条件**——「国有独资或国有控股」在 56 号令第八条，是**全体申请人的基本条件，不按类别放宽**。所以「按类别找宽松档位」这条路不存在。

**第七条留有「或履行备案手续」这条替代路径，但用不上**：第十条第二款限定「**地（市）级以上广播电台、电视台**从事互联网视听节目**转播类**服务」及中央新闻单位转播类 → **民营自营内容不在备案范围内**（44 号通知同口径：不需办理许可证的只有这些主体）。2020 年另开的一条免「国有」通道（广电发〔2020〕61 号，经北京市广电局办事指南原文引用）只给**市县级地方新闻单位**（广播电视台、报刊社、县级融媒体中心）。

**自营免费音频故事按目录会归到哪一类**：最接近 **第二类(三)**「文艺、娱乐、科技、财经、体育、教育等专业类视听节目的制作（不含采访）、播出服务」，其界定原文「生产制作、定制、编排……并供公众在网上点播」用词形态中立。⚠️ **目录里没有「音频故事/AI 生成内容」这一项，该归类是据界定文字作的解释性涵摄，无官方对应文字** ⏳。好消息：按总局服务指南七(二)，落在第二类(三)**不额外**要求制作经营许可证（只有主持访谈报道类、自办网络剧片类才叠加）。

一般项目：软件开发；技术服务、技术开发、技术咨询、技术交流、技术转让、技术推广；

### 逐条取舍

| 条目 | 建议 | 理由 |
|------|------|------|
| `软件开发` | **必留，放第一项** | 与字号中的行业用语对应（如「…软件开发工作室」）；技术协议与软著的主体依据 |
| `技术服务、技术开发、技术咨询、技术交流、技术转让、技术推广` | **必留** | 这是**一个**标准条目（六词打包）；开票「技术服务费」要能落到条目上 |

| `数字内容制作服务（不含出版发行）` | **必留** | 最贴本项目：AI 生成故事文本 + 插图 + 音频；括号内已排除「出版发行」，不触许可 |
| `教育咨询服务（不含涉许可审批的教育培训活动）` | 建议留 | 儿童相关产品的说明面；括号内明确**不是培训**，避开《民办学校办学许可证》 |
| `广告设计、代理` | 将来再加 | 只有接广告位才用得上 |
| `互联网销售（除销售需要许可的商品）` | 将来再加 | 只有卖实体绘本/周边才用得上 |
| `计算机软硬件及辅助设备零售` | **删** | 与本项目无关，别为凑数加 |

### 千万别勾（勾了就要办证，办不下来就是障碍）

`互联网信息服务` / `第二类增值电信业务`（ICP 许可）· `网络文化经营`（文网文）· `音像制品` / `出版物零售` · `广播电视节目制作经营` · `教育培训` / `学科类培训` · `网络游戏`（版号）

> 原则：**只描述「我做软件、做技术服务、制作数字内容」，不描述「我运营一个内容平台」。**

**为什么不要「预防性留口子」**（有人会说先把「互联网信息服务；第二类增值电信业务（凭许可证经营）」写上以便日后办证）：这两条属**许可项目**，写进执照就意味着你要持证经营；不办证而写入，登记与税务侧都可能被要求说明，且个体户本就办不下来。而变更经营范围是线上、免费、几个工作日的事。**确定性成本为零、不确定性代价高时，不留口子。**

顺带一条与文案有关的风险：`数字内容制作服务（不含出版发行）` 这个括号里的「**不含出版发行**」正好是本项目要的边界——我们制作内容，但**不宣称自己是出版物**。对应到小程序侧就是**不要申请「出版」类目**，见 §6。

## 4. 注册操作要点

| 项 | 怎么选 |
|----|--------|
| 组织形式 | 个体工商户。名称格式 `行政区划 + 字号 + 行业 + 组织形式`，后缀用**工作室 / 中心 / 部**，**不能叫「公司」**。字号避开他人 IP 与品牌词 |
| 经营场所 | 有地址证明就自填；没有用当地**集群注册/托管地址**（孵化器提供，年费通常几百到一千余）。住宅改经营各地规则不同 |
| 验证方式 | 对公打款 **或** 微信认证（300 元）二选一。**建议直接做微信认证**：一步解锁手机号验证、URL Scheme/Link、直播准入 |
| 银行账户 | 先不开对公。微信支付商户号可用**经营者本人借记卡**（对私结算） |
| 税务 | 领照后在电子税务局启用税种，选小规模纳税人；开票时税收分类编码要落在所勾条目上。问当地是否仍可**核定征收/定期定额**（多地已转查账征收） |
| 社保 | 无雇工可不办单位社保户，自己走**灵活就业**参保 |
| 变更成本 | 增减经营范围通常线上办、免费、几个工作日 → **宁少勿滥，用到再加** |
| 记账 | 收入起量后请代账（个体户档约 100-300/月），别自己硬扛申报 |

## 5. 与小程序/供应商对齐的一致性（最容易出错的地方）

**四处主体名称 + 统一社会信用代码必须一字不差**：

```
营业执照  ─┬─→ 微信小程序注册主体（类型选「个体工商户」+ 经营者身份证）
           ├─→ 微信认证主体
           ├─→ 微信支付商户号主体（否则商户号无法与小程序关联）
           └─→ 火山/模型供应商合作协议抬头
```

另有一条官方口径要盯：「**备案主体与小程序主体一致，否则补授权**」→ 若技术方（火山）的算法备案主体与协议签约主体不同，需要授权链证明，提前向对方索取。

**将来卖会员/次数（第二版）的收费形态，不是接普通微信支付**：

- 安卓侧：官方运营指南原文——「若小程序仅包含以上虚拟类目，平台将**关闭该小程序在安卓**及其余非 iOS 系统的普通微信支付能力，需调用**小程序虚拟支付**能力进行交易」。
- iOS 侧：「小程序虚拟支付在 iOS 端提供会员订阅能力。用户完成一次签约后，由 **Apple 按周期自动扣费**」。
- 技术服务费：主动支付标准 10%、当前 **1%**；会员订阅首笔 1%、第二笔起 10%。
- 首版**不接任何支付**，所以不受影响；但会员体系设计时按「虚拟支付」这套规则做，别按普通微信支付做。

## 6. 小程序备案（强制，且是 M0 的长周期关键路径）

⚠️ **和你已有的「域名 ICP 备案」是两件事**。境内小程序作为 APP 类主办者须单独完成备案：工信部信管〔2023〕105 号 + 微信备案文档同口径——「未备案不得从事互联网信息服务」，**未备案的小程序不可访问 / 会被下架**，无豁免。

| 项 | 内容 |
|----|------|
| 主体类别 | **个体工商户按「单位主体」办理**（不是按个人） |
| 材料 | 营业执照 + 主体负责人身份证件 + 小程序负责人身份证件 |
| 流程 | 填信息 → 平台初审 1-2 工作日 → 工信部短信核验（**24 小时内必须点**）→ 通管局审核 **1-20 工作日** → 备案成功 |
| 是否要 ICP 经营许可证 | **不要**。备案材料不含增值电信业务经营许可证 |
| 前置审批 | 只在**实际从事**新闻、出版、教育、药品医疗器械、文化、广播电影电视节目、校外培训、宗教等业务时才需提交对应前置审批文件。**⚠️ 这一项是本次核实的新风险入口**：备案的「服务内容」选择里就有「音乐 / 电台 / 有声读物」，微信原文标注「个人备案：不建议选择；**单位备案：可选，需要资质**；资质上传位置：**前置审批位置**」→ 选到这三项等于自己在备案阶段伸手要证。⏳ 该页**没有**任何 AI/深度合成对应的服务内容条目 |

**三个必须避开的动作**：

1. **别申请「出版」类目**。《网络出版服务管理规定》第二条(一) 对「网络出版物」的定义**明文含「音视频读物」**，AI 故事文本 + 音频在字面上可被归到出版/网络出版（该类目要求《互联网出版许可证》/《网络出版服务许可证》/《出版物经营许可证》三选一，前两张个体户办不下来，第九条另要求 8 名以上专职编辑）。产品与页面文案统一说「**AI 生成的睡前故事**」，**不出现**「绘本」「故事书」「电子书」「出版」「读物」这类词；类目也不要在「深度合成」之外去挂书刊/教育出版物。
2. **备案「服务内容」与小程序简介里别写音频形态的触发词**。不选「音乐/电台/有声读物」，简介与详情描述里不出现「**听书 / 电台 / FM / 频道 / 节目 / 栏目 / 读物**」——这些词正好是「文娱-电台」（适用范围含「音频节目」）与「文娱-有声读物」（适用范围「版权读物的语音播报」）的字面触发条件，而那两项的材料个体户交不出（见 §2）。⚠️ 这**不是**法律豁免，只是不主动把形态声称出去。
3. **短信核验超时会导致流程重来** → 提交当天让负责人手机保持可达。

**周期影响**：通管局最长 20 工作日，**必须和注册执照并行启动、不能等代码写完**。原以为 M0 没有长周期项，这里出现了唯一一个。

## 8. 登记前后要打的六通电话（前两通决定项目能不能存在）

> **每通都要：要工单号/邮件等书面留痕，要录音，把问题原文念给对方。** 口头「应该没问题」不算答复——本项目现在最关键的三个问题，官方都**没有成文口径**，只能靠问出来并留痕。

1. **微信侧（小程序后台类目咨询 / 官方工单）——新第一优先，比火山协议更靠前**：问题原样问「**个体工商户**小程序使用第三方**已备案**的语音合成（TTS）能力生成朗读音频，在『深度合成』五个子项（拟人化互动/AI问答/AI换脸/AI绘画/AI创作，适用范围原文均为文本/视频/图片/情感互动）中应挂哪一项？若挂『AI创作 + AI绘画』，是否会被要求补『文娱-电台』或『文娱-有声读物』类目？**产品提供的是单次 AI 生成的**原创**故事的语音播报，不是播放已有版权读物。**」
   → 这一条是本次核实新发现的**结构性缺口**：类目表里没有任何覆盖语音合成的子项，而文娱那几项的材料个体户交不出。答案若为「需补文娱类目」，**整个产品形态在个体工商户下不可上架**，优先级高于供应商协议。
2. **国家广播电视总局政务服务大厅 010-86098585 + 属地省广电局网络视听处**：问题原样问「**个体工商户**通过微信小程序向公众提供 AI 生成的**免费**音频故事（**不开放用户上传、不收费**），是否属于《互联网视听节目服务管理规定》第二条的互联网视听节目服务、是否须取得《信息网络传播视听节目许可证》或被要求纳入备案？」

## 9. 跟踪项（会改变上面结论的法规动态）

- **《互联网信息服务管理办法》修订**：网信办 2026-07-03 征求意见稿拟**取消经营/非经营二分**，改为「从事互联网信息服务，应当依法取得电信主管部门核准」+「属于经营电信业务的，应申请取得相关电信业务经营许可」（截止 2026-08-02 征求意见，**尚未生效**）。若按此通过，第一版「免费就不需要许可」的判定要重新评估。
- **国务院《保障未成年人健康安全使用网络的规定》**：2026-09-19 仍在征求意见，通过后对儿童产品的防沉迷/身份核验义务会加码。
- **《人工智能拟人化互动服务管理暂行办法》**（2026-07-15 已施行）第十四条要求未成年人模式、不满十四周岁需监护人同意；但「智能客服等不涉及持续情感互动的不适用」→ **单次生成故事可主张不适用；一旦做成「故事姐姐」长期陪伴式对话就落入**。这是首版不做 AI 对话的**法规依据**（此前只引了微信条款）。
- **《未成年人网络保护条例》第四十二条**：「应当建立健全**防沉迷制度**，不得向未成年人提供诱导其沉迷的产品和服务」——直接适用。README 里「不做自动连播/无限推荐」不只是产品原则，是法定义务。
- **视频形态何时变成硬约束**：若微信侧把 AI 生成视频明确挂到文娱/视听类前置审批，或属地主管部门对「纯音频故事」也按视音频节目口径要求许可，则 §2 第三个触发点从「将来」变成「现在」。这类判定目前**未找到官方依据**，不要凭猜测提前变更主体。
