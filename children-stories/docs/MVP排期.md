# MVP 排期与优先级

范围锁定：5-7 岁睡前 · 逐句高亮 + AI 配图 + 收藏/历史/系列 · 火山 TTS + 方舟 Seedream · 自建 Java 后端 + 已备案域名 · 首版免费不接支付。

---

## 1. 里程碑总览

| 阶段 | 周期（参考） | 目标 | 阻塞项 |
|------|-------------|------|--------|
| **M0 对齐 + 前置准备** | 2-4 天（**但小程序备案审核 1-20 工作日并行**） | 需求冻结、供应商开通、执照与**小程序备案**提交、子域名/证书/白名单 | 🔴 **音频类目落脚点（开工前两通电话，见 §7 第 0 步）**；小程序备案是长周期项，注册执照当天就提交，别等代码 |
| **M1 生成闭环（无 UI）** | 1 周 | 后端跑通「一句话 → 结构化故事 → mp3 + 句级时间戳 → **写元数据标识** → OSS」，用 curl/Postman 验收 | 火山 TTS 分段上限实测；**mp3 元数据隐式标识必须在 M1 就做**（事后补等于重生成全量文件） |
| **M2 小程序骨架 + 输入页** | 1 周 | 登录、P1 输入页、P2 进度页（轮询）、真实端到端一次生成 | — |
| **M3 播放页（产品心脏）** | 1.5 周 | 逐句高亮、自动翻页、后台熄屏播放、语速、定时、收藏 | `getBackgroundAudioManager` 约束实测 |
| **M4 配图 + 审核 + 我的** | 1.5 周 | 角色一致性生图、输入/输出/图片三重审核、收藏/历史/孩子档案 | 图片审核接口版本确认；**若 §7 第 0 步的音频类目答复为「需补文娱类目」，M4 之前必须先重开形态评估** |
| **M5 打磨 + 提审** | 1 周 | 降级与限流、成本熔断、隐私协议、真机走查、提交审核 | AIGC 类目材料（见 README §10） |

合计约 **7-8 周**（1 人全职）。你一人做前后端，我建议按 M1→M3 优先，M4 的配图可以最后补——它是范围里最贵、最耗时、也最容易砍的一块。

**如果人力要压缩到 5 周**：把「AI 配图」降到 Should（只出 1 张封面），把「轻音乐混音」「语速重合成」砍掉。核心闭环（输入→流式故事→高亮朗读→收藏）不动。

## 2. 优先级（MoSCoW）

### Must

- [ ] 一句话输入 + 8 个主题 chips 兜底
- [ ] 时长/音色/寓意/背景音/孩子 5 项参数
- [ ] 结构化生成（5-7 段 + 标题 + characterAnchor + moral）与服务端后置校验
- [ ] 流式分段显示 + 分阶段进度 + 取消 + 同 requestId 重试不扣额度
- [ ] 输入文本审核 + 输出文本审核 + 生成图片审核（三重，审核不可用即拒绝）
- [ ] 火山 TTS：chunked 聚合 → 完整 mp3 → 字级派生句级时间戳 → 转存 OSS
- [ ] 逐句高亮播放、段自动翻页、横滑翻段、点击句子 seek 重播
- [ ] **熄屏/后台连续播放**（`getBackgroundAudioManager`）
- [ ] **由用户点击起播，全程无自动播放**（拒绝情形 3.5.2「禁止视频、音乐、语音等多媒体的自动播放」）
- [ ] **mp3 文件元数据写入 AI 生成隐式标识**（《标识办法》第五条：内容属性 + 服务提供者名称或编码 + 内容编号；无二选一）
- [ ] AI 配图每段一张 + 参考图角色一致性 + 异步淡入 + 占位兜底
- [ ] 微信登录、收藏、历史、孩子档案（小名）
- [ ] 每日人均额度 + 平台日总额熔断 + 成本流水表
- [ ] 「故事与插图由 AI 生成」常驻标识、隐私政策、用户协议、反馈入口

### Should

- [ ] 轻音乐/白噪声混音（`-18dB` + 结尾淡出）—— 成本低、睡前氛围收益高，我建议在 M4 顺手做掉
- [ ] 语速 0.8/1.0/1.2（每档各自合成 + 本地缓存命中）
- [ ] 「同样参数再来一篇」（避免与上一篇标题/开头重复）
- [ ] 定时停止 15/30 分钟
- [ ] 失败原因友好文案表（供应商 code → 家长话术）
- [ ] 空态/弱网重试/下拉刷新

### Could

- [ ] 角色一致性进阶：孩子小名做成故事里的「朋友」而非主角（避免让兔子叫乐乐）
- [ ] 简单数据统计（人均篇数、完成率、次日留存）
- [ ] 音频回收与生命周期任务
- [ ] LLM 双供应商自动切换（M1 先做手动切换开关）

### Won't（第一版明确不做）

- 分享海报（你没选，第二版第一候选，是自然拉新路径）
- **音频下载/导出**（《标识办法》第四条末句：提供下载/复制/导出时须确保**文件内含显式标识** → 就得把提示音做进 mp3，毁掉睡前氛围。不做导出则只需界面提示 + 元数据隐式标识，已足够）
- **真 AI 视频生成**（类目推向个体户结构性拿不到的许可，见 `docs/视频形态评估.md`）
- 社区、评论、UGC 公开内容
- 孩子录音复述/口语打分（要额外资质与成本）
- 付费/会员/支付（个人主体也接不了）
- 英文故事、自动连播、防沉迷「上瘾」型推荐
- H5 / App 端

## 3. 分周任务拆解

### Week 0（M0）

- 🔴 **先打两通电话，再决定要不要开工**（问题原文已备好，见 `docs/主体与证照准备.md` §8 第 1、2 通）：
  1. 微信官方工单：**朗读音频（TTS）在深度合成 5 个子项里挂哪一项**、会不会被要求补「文娱-电台 / 文娱-有声读物」；
  2. 广电总局政务服务大厅 `010-86098585` + 属地省广电局网络视听处：**个体工商户经微信小程序向公众提供 AI 生成的免费音频故事，是否属《互联网视听节目服务管理规定》第二条的互联网视听节目服务、是否须持《信息网络传播视听节目许可证》或被要求纳入备案**。

  → 第 1 通的答复若是「需补文娱类目」，那些证照全部要求「具备法人资格」（视听证另加国有独资或控股）→ **该产品形态在个体工商户下不可上架**，此结论比写代码优先。每通都要：念原问题、要工单号或邮件等书面留痕、录音。
- **注册个体工商户 + 同日提交小程序备案**（通管局 1-20 工作日，是本项目唯一长周期项）。经营范围勾选、备案材料与流程时限见 `docs/主体与证照准备.md` §3/§6；短信核验 24 小时那一步最容易错过。**备案的「服务内容」项不要选音乐/电台/有声读物**（该页标注「单位备案：可选，需要资质 / 资质上传位置：前置审批位置」，选了就是自己伸手要证）
- **问属地网信办「生成式 AI 应用登记」**：官方口径是调用已备案模型做接入方**只做登记、不重复备案**，但入口与材料按属地执行，早问早闭环
- 域名已备案 → 只需：加子域名（如 `api.xxx.com`）、HTTPS 证书、对象存储/CDN 绑定、在小程序后台配 request/uploadFile/downloadFile 合法域名并放校验文件。**当天可完成**
- 火山引擎：开通豆包语音（记下 `X-Api-Resource-Id` 实际取值）+ 方舟 Seedream，拿到 Key，跑通最小合成与最小生图
- LLM 选型（主/备各一），确定结构化输出可用
- **合规材料启动（第一天就做，长周期项）**：向火山与 LLM 供应商索取「算法名称 / 应用场景 / 备案编号」齐备的合作协议文本，⚠️ **协议里的算法名称与应用场景必须同时覆盖语言大模型、图像生成、语音合成三项**（只写文本与图像 → 音频被追问材料时手上没东西）；在小程序后台核「深度合成」类目对个体工商户的实际可选项与材料清单；配 `requiredBackgroundModes: ["audio"]` 并写清用途说明
- `app.json` 早期就加 `requiredBackgroundModes`，并在后台填《用户隐私保护指引》（首版只声明 openid 相关的必要项，不申请麦克风/相册/位置）
- 服务器与后端工程、CI 骨架就位
- 冻结视觉：从 `docs/页面与交互.md` 的暖色调色，出 1 张播放页高保真即可开工。**起播交互按「点一次播放键」定稿**（3.5.2 禁自动播放），别等高保真出来再改

### Week 1-2（M1）后端生成闭环

- `POST /stories` + 轮询 `progress`，状态机（`AUDITING → GENERATING_TEXT → SYNTHESIZING_AUDIO → READY/FAILED`）
- LLM 适配层 + Prompt 落地 + 后置校验（字数/段数/禁词/结构）
- TTS 适配层：**chunked 聚合单测**（重点实测 v3 文本上限，验证是否需要分段 + 偏移累加）
- 句级时间戳派生（秒 → ms）+ 估算兜底路径
- OSS 转存 + 签名 URL；`requestId` 幂等；额度扣减与返还
- 用 curl 走一遍：输入 → 拿到完整 mp3 URL + 42 句时间戳。**这一步不通就别写前端**

### Week 2-3（M2）小程序骨架

- 工程、tabBar、路由、请求层与 token、错误码拦截
- P1 输入页（chips/参数/额度/最近列表）+ 隐私弹窗 + 静默登录
- P2 进度页 + 轮询节流 + 取消/重试 + 失败态
- 端到端真机跑通一次（先无图，`imageUrl=null` 走占位）

### Week 3-5（M3）播放页

- `BackgroundAudioManager` 接入（title/cover/src、后台与熄屏实测）
- `onTimeUpdate` 250ms 节流 + 二分定位当前句 + 只 setData 索引
- 段自动翻页动画、横滑翻段、点句 seek、进度条
- 语速切换（走后端重合成 + 本地缓存）
- 真机 iPhone + Android 走查：锁屏控制条、暗光观感、安全区

### Week 5-6（M4）配图与审核

- Seedream 适配：段 1 定妆 → 参考图传段 2-6 → 并行 5 路 → 全部转存
- 三重审核接入 + 审核拦截降级（换 prompt / 占位卡 / `40011`）
- P4 我的：孩子档案、收藏/历史 Segment、软删
- 生命周期回收任务（未收藏 30 天）

### Week 6-7（M5）打磨提审

- 人均额度 + 日总额熔断 + 成本日报（`t_cost_daily`）
- 降级演练：TTS 挂 → 纯阅读；图挂 → 占位；审核挂 → 拒绝；LLM 挂 → 备用
- 隐私协议/用户协议/AIGC 标识文案、类目材料补齐
- 对照 §4 验收清单真机全流程走查 → 体验版内测 → 提审

## 4. 验收清单（提审前逐条真机过）

| # | 场景 | 通过标准 |
|---|------|----------|
| 1 | 冷启动进 P1 | 默认「中/温柔姐姐/雨声」，额度显示正确，无需登录即可输入 |
| 2 | 空输入 / 2 字以内 | 按钮置灰或抖动提示，不发请求 |
| 3 | 输入含敏感词 | 服务端拦下，文案 `这句话我们讲不了`，**额度不扣** |
| 4 | 点 chips | 填入输入框可编辑，不直接生成 |
| 5 | 正常生成 | 首段文字 ≤4s 可见；可播 ≤12s（P50）；跳 P3 后**停在待点播放键**，点一次才起播（3.5.2 禁自动播放） |
| 6 | 逐句高亮 | 高亮与声音偏差 < 0.4s；段切换自动翻页；不逐字抖动 |
| 7 | 熄屏播放 | 锁屏后继续播放，锁屏控制条可暂停/继续，音量正常 |
| 8 | 点击某句 | seek 到该句起始并重播，高亮正确跟随 |
| 9 | 横滑翻段 | 图与文字一起切，声音 seek 到该段首句 |
| 10 | 语速切到 1.2 | ≤3s 生效；切回 1.0 命中缓存秒回 |
| 11 | 定时「播完停止」 | 结束停在末段显示晚安，**不自动播下一篇** |
| 12 | 配图一致性 | 6 段里同一只兔子（颜色/配饰不变）；图未到时占位不阻塞 |
| 13 | 图全失败 | 占位卡 + 正常播放，无报错弹窗 |
| 14 | TTS 失败 | 进入纯阅读模式，可手动「重试配音」 |
| 15 | 收藏 | 列表可见、可取消；收藏项不被 30 天回收删掉 |
| 16 | 历史/系列 | 「给乐乐的第 N 个故事」计数连续、正确 |
| 17 | 额度用尽 | 按钮置灰 + 文案；第二天 0 点重置 |
| 18 | 生成中重复点重试 | 同 requestId 不产生第二条故事、不重复扣额度 |
| 19 | 越权访问 | 用 A 的 token 请求 B 的 storyId 返回 403 |
| 20 | 弱网/断网 | 保留已显示段落、有重试入口、不白屏不崩溃 |
| 21 | AIGC 标识 | 播放页常驻「内容由AI生成」，含「AI生成」四字原样，不可折叠隐藏 |
| 22 | 隐私弹窗 | 首次触发授权；未同意时不调用受限接口 |
| 23 | iPhone/Android | 底部安全区、暗色不刺眼、最长段文字不溢出 |
| 24 | 成本 | 单篇成本记录进流水；日总额达阈值触发 `42900` 熔断 |
| 25 | 生成中锁屏再回前台 | `onShow` 重新拉 progress，已生成内容完整显示，不报错不卡住（官方：后台 5s 内未结束的请求会回调错误） |
| 26 | 图片异步复核撤回 | 模拟 `mediaCheckAsync` 回调判危 → 该段降级为占位卡，故事标 `risk_flag`，不白屏、不打断播放 |
| 27 | 定时档位后台行为 | 熄屏后 15/30 分钟档不生效的表现符合 UI 说明（`需保持前台`）；「播完停止」在后台正常收尾 |
| 28 | 隐私声明缺失 | 未声明的接口调用返回 `112`/`101101`/`101102` 时不崩，有可诊断日志（这类是配置问题，不是代码 bug） |
| 29 | 未上架额度 | 内测期 `msgSecCheck` 接近 100 次/天时不整片失败：命中本地缓存或走「稍后再试」友好提示 |
| 30 | **音频文件隐式标识** | 抽查 OSS 上的 mp3：文件元数据含「内容属性 + 服务提供者名称或编码 + 内容编号」三要素（第五条，无二选一）。写成待办不算过 |
| 31 | 多媒体非自动播放 | 全流程无任何「进页面就自己响」：生成完成、切段、重播均需一次点击；`autoplay` 相关代码路径为关闭 |

## 5. 风险与对策

| 风险 | 严重度 | 对策 |
|------|--------|------|
| 🔴 **朗读音频在微信类目表里没有落脚点**：深度合成 5 个子项（拟人化互动/AI问答/AI换脸/AI绘画/AI创作）的适用范围原文分别是 情感互动/**文本**/**视频**/**图片**/**文本**，**无一项覆盖语音合成**；未找到微信官方对此的任何 FAQ 或社区回复 | **可能决定整个产品能否上架**（比供应商协议更靠前） | ①**开工前**打微信官方工单，要书面答复（`docs/主体与证照准备.md` §8 第 1 通）；②抗辩点：类目表交叉注释写的是「语音播放**版权读物**需补【文娱-有声读物】」，我们播的是单次 AI 生成的**原创**故事 → 简介/详情页**绝不出现「听书/读物/电台/节目」**；③协议里的算法名称与应用场景必须覆盖**文本+图像+语音合成**三项 |
| **文娱-电台/有声读物的证个体户交不出**（2 选 1 / 4 选 1，全部要求「具备法人资格」，视听证另加国有独资或控股） | 换普通公司也解不开视听证 → 结构性不可补 | 若工单答复为「需补文娱类目」→ **该产品形态在个体工商户下不可上架**，届时三选一：纯文字+图片上架（砍朗读，等于放弃产品本体）、换主体但仍缺国有背景（走不通）、只做自用不上架。**这就是第 1 通电话必须先打的原因** |
| ⚠️ **纯音频很可能在「视听节目」射程内**（39 号令第二条定义明文含「**或可连续收听的声音**」；总局持证目录含喜马拉雅等纯音频平台），且**免费与不开放 UGC 都不构成豁免**（56 号令第二条无营利限定、两种情形并列） | 理论敞口：警告 + 3 万以下罚款（罗湖案实罚 1 万，自然人无照）。真正未表态的窄问题是「单次生成的 400 字音频算不算一个**节目**」 | 打总局政务服务大厅 `010-86098585` + 属地省广电局网络视听处要书面答复；在此之前保持「不栏目化/不连播/不收费/不开放上传/文案无读物电台节目」的解释姿态（**是姿态，不是豁免**） |
| ❌ **3.5.2 禁止多媒体自动播放**（原文「禁止视频、音乐、语音等多媒体的自动播放」）与原设计「音频就绪即播」直接冲突 | 代码审核直接被拒 | **已改**：就绪后跳 P3 停在待点播放键，家长点一次起播（P2/P3 与 §4 第 5 条已同步）。段间、重播、回前台一律不起播。⚠️ 不得用延迟/伪装绕过（2.5.19 最重可到永久下架） |

## 5.5 「先开发、自己测、上架再验证」成立吗——成立，但有五条例外

| 类别 | 项 | 必须动的时点 |
|------|----|-------------|
| ✅ **真的只是上架才验证** | 类目材料提交、算法备案编号原件、微信认证（300 元）、提审文案终审、`requiredBackgroundModes` 的**正式版**审核（官方原文：开发版/体验版直接生效） | 提审前 1-2 周对齐即可 |
| ⚠️ **是上架要求，但获取周期长于开发周期** | 小程序备案（1-20 工作日）、供应商合作协议 + 备案编号（商务周期不可控）、个体工商户注册（这三条的第一张多米诺） | **第 0 天**，与写代码并行 |
| ❌ **不是上架才要，开发阶段就会咬你** | ①《用户隐私保护指引》逐项声明——未声明的接口在**开发版/体验版**就返回 `112`/`101101`/`101102` 被直接禁用；② request/uploadFile/downloadFile **合法域名白名单**——真机联调前不配，请求全 fail；③ `msgSecCheck` **未上架 100 次/天**——内测规模要按它反推（≤15 人） | 第一次真机联调前 |
| ❌ **同样是开发阶段就要改代码，但原因是审核条款而非技术限制** | ① **3.5.2 禁止多媒体自动播放** → 起播必须由用户点击，不能「就绪即播」（已改 P2/P3 与 §4 第 5 条）；② **《标识办法》第五条 mp3 元数据隐式标识** → M1 的音频构建步骤里就要写，事后补等于重新生成全量文件 | **写第一行音频代码之前** |
| 🔴 **与验证时机无关，是「这个形态有没有落脚点」** | ① **朗读音频在微信类目表里无对应子项**（深度合成 5 项只覆盖 情感互动/文本/视频/图片/文本，无语音合成）→ 若被要求补文娱-电台/有声读物，那些证全部要求法人资格，**个体户交不出、民营公司也解不开视听证的国有控股**；② **真 AI 视频**形态 | **开工前打那两通电话**（`docs/主体与证照准备.md` §8 第 1、2 通） |

判定口径的差别在最后一行：文本/图片即使合规有不确定性，最坏结果是**被要求补材料**，代码不白写；而**朗读音频和视频**这两条，最坏结果是**类目层面根本没有可提交的材料**。所以它们的排序与其他功能相反——**先定落脚点，再写代码**。

> ⚠️ 这条结论是本轮核实后**改过来的**。在此之前我把「深度合成类目对口本产品」当作已成立的前提，实际只核到文本与图片两项，音频那项**在类目表里不存在**。

### 6.2 内容安全（条款是强制的）

### 6.3 AIGC 标识

- [ ] 类目表备注原文：「所有人工智能生成合成内容……需在 AI 生成内容显著位置进行标注，如：明确标注为『AI生成、人工智能生成』或同等含义字样」。
- [ ] 播放页与生成结果处**常驻**「内容由AI生成」字样（确保出现「AI生成」四字），不可折叠、不可被截图裁掉。
- [ ] **音频的显式标识有官方给的二选一**：《人工智能生成合成内容标识办法》（国信办通字〔2025〕2 号，**2025-09-01 已施行**）第四条(二) 原文「在**音频**的起始、末尾或者中间适当位置添加**语音提示或者音频节奏提示**等标识，**或者在交互场景界面中添加显著的提示标识**」→ **我们走后半个「或者」**，即 P3 那行常驻小字，**不必在 mp3 里插一句口水音**（睡前场景里那一声比什么都破坏氛围）。
- [ ] ⚠️ **但隐式标识没有二选一，是硬要求，且要写进文件**：第五条原文「在生成合成内容的**文件元数据**中添加**隐式标识**，隐式标识包含**生成合成内容属性信息、服务提供者名称或者编码、内容编号**等制作要素信息」→ **mp3 转存 OSS 之前必须写完元数据**，落成 `docs/接口与数据.md` §3 的构建步骤与 §4 验收第 30 条。
- [ ] **一旦将来提供下载/导出，义务会升级**：第四条末句「服务提供者提供生成合成内容**下载、复制、导出**等功能时，应当确保文件中含有满足要求的**显式标识**」→ 那时必须把提示做进音频本体。所以**首版不提供音频导出**是最省事的合规姿态（写进 Won't）。

### 6.8 小程序备案与法规义务（微信条款之外，官方原文已核实）

- [ ] **完成小程序备案（强制，无豁免）**：工信部信管〔2023〕105 号 + 微信备案文档口径「未备案不得从事互联网信息服务」，未备案不可访问/下架。个体工商户按**单位主体**办，材料 = 营业执照 + 主体负责人证件 + 小程序负责人证件；流程 5 步，**通管局 1-20 工作日**，工信部**短信核验须 24 小时内完成**。
- [ ] 备案材料**不含**增值电信业务经营许可证；只在实际从事新闻、出版、教育、医药、文化、广电、校外培训、宗教等业务时才需前置审批文件 → **本项目一项都不要碰**。
- [ ] **不申请「出版」类目**。禁的是「把产品自称成出版物」——用户可见文案不说「绘本 / 故事书 / 电子书 / 出版物 / 读物 / 上架发行」，统一说「**AI 生成的睡前故事**」；美术风格与内部文档里描述「绘本插画风格」不受影响（那是风格词，不是出版声称）。经营范围那条 `数字内容制作服务（不含出版发行）` 的括号正好是这个边界。
- [ ] **生成式 AI 走「登记」不走「备案」**：网信办 2026-05-13 公告原文「通过 API 接口或其他方式直接调用已备案模型能力的生成式人工智能应用或功能，由地方网信办开展登记」。属地入口与材料要问当地网信办。
- [ ] **算法备案的法规门槛 ≠ 微信要求**：深度合成规定第 19 条只对「具有舆论属性或者社会动员能力」的服务强制备案，本产品大概率不属此类；但**微信侧仍要求技术方备案证明 + 含要素的合作协议**，按微信口径准备。
- [ ] **《未成年人网络保护条例》第四十二条**：「应当建立健全防沉迷制度，不得向未成年人提供诱导其沉迷的产品和服务」→ 「播完即停、不自动连播、无无限推荐、每日时长提示」按硬编码实现。第二十四条另要求：专门以未成年人为服务对象的产品不得制作/传播可能影响身心健康的信息 → §6.2 的输出审核就是这条的执行手段。
- [ ] **《人工智能拟人化互动服务管理暂行办法》**（2026-07-15 施行）第十四条含未成年人模式与不满十四周岁需监护人同意；办法对「不涉及持续情感互动的」不适用 → **首版单次生成可主张不适用，一旦做角色陪伴就落入**，这是 Won't 的法规依据。
- [ ] **AIGC 标识另有法规来源**：《人工智能生成合成内容标识办法》与深度合成规定第十七条（文本生成、合成人声明列需显著标识）→ §6.3 的标识不是只做给微信看。
