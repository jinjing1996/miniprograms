# 页面与交互

共 4 个页面 + 1 个 Tab 结构。配色基调：暖米白 `#FBF4E8` / 深棕字 `#4A3B2A` / 柔和橘 `#E9A15B`；禁用纯白高对比（睡前暗光）。字号基线 18px，当前高亮句 24px。

---

## P0 Tab 栏

| Tab | 页面 |
|-----|------|
| 讲故事 | P1 输入页（也是首页） |
| 我的 | P4 我的页 |

P2 生成进度、P3 播放页是 P1 推入的普通页面，不进 Tab。

---

## P1 讲故事（首页 / 输入页）

```
┌──────────────────────────────┐
│  小故事的睡前时光              │  ← 标题（轻）
│                              │
│  今晚想讲点什么？              │  ← 主标题 20px
│ ┌──────────────────────────┐ │
│ │ 小兔子第一次自己睡觉        │ │  ← 输入框 ≤40字
│ └──────────────────────────┘ │
│ 不知道写什么？试试：            │
│ [怕打雷] [分床睡] [第一天上学]   │  ← 8 个 chips，可横滑
│ [被抢玩具] [牙齿掉了] [交朋友]   │
│                              │
│ 时长   (短3分) (●中5分) (长8分) │
│ 音色   (●温柔姐姐)(故事爷爷)(小伙伴)│
│ 结尾加一句道理   [●开]         │
│ 背景音  (关)(八音盒)(●雨声)(白噪) │
│ 讲给     (●乐乐) (+ 新建)      │
│                              │
│ ┌──────────────────────────┐ │
│ │      生成故事  今日剩 3 次   │ │  ← 主按钮
│ └──────────────────────────┘ │
│                              │
│ 最近                          │
│ ┌────┐ 小兔子自己睡觉   5分钟 ⭐ │  ← 卡片，点击直接重播
│ └────┘ 乐乐的第一天上幼儿园 8分钟│
└──────────────────────────────┘
```

**交互要点**

1. chips 点击 = 填入输入框并把光标置末，不直接生成（家长常要改两个字）。
2. 输入为空时主按钮置灰，文案 `先写一句话`；额度用尽时文案 `今日次数用完了，明天再来` + 不可点。
3. 所有参数选中即生效、无「确认」弹窗；点主按钮后立刻跳 P2。
4. 首次进入：弹一次隐私授权（微信官方隐私弹窗），不做引导蒙层——困了的家长不会看完蒙层。
5. 未登录：本地先渲染，点主按钮时才静默 `wx.login`；失败才提示。

**校验**：输入去首尾空格后 < 2 字 → 抖动提示 `再多写一点点？`；> 40 字截断并提示。含敏感词由服务端审核返回后提示 `这句话我们讲不了，换一个试试`。

## P2 生成中（进度页，10-25s）

```
┌──────────────────────────────┐
│  ←                           │
│  正在给乐乐编故事              │
│  ●●●○○  在想故事…            │  ← 阶段指示 + 文案
│                              │
│  小兔子第一次自己睡觉          │  ← 标题，出来即显示
│                              │
│  ① 兔子的房间今晚特别安静…     │  ← 段落逐段淡入（流式）
│  ② 它抱紧小毯子，数到十…       │
│  ③ ▌                         │  ← 正在生成，光标闪烁
│                              │
│  插图 2/5 · 声音准备中         │  ← 次要状态，小字
│                              │
│         [ 取消 ]             │
└──────────────────────────────┘
```

**阶段文案（按真实进度驱动，不是假动画）**

| 阶段 | 文案 | 触发 |
|------|------|------|
| 审核 | `听听这句话…` | 输入审核中 |
| 生成 | `在想故事…` → `写下来啦，一段一段给你看` | 首 token 前/后 |
| 配图 | `正在画插图` | 首图请求发出 |
| 配音 | `请来温柔姐姐念给你听` | TTS 开始 |
| 就绪 | `可以开始啦` → 停在 P3，**播放键高亮待点** | 音频就绪（**不等图片**） |

**要点**

- 段落一到即渲染，滚动跟随；图片占位为暖色圆角块 + 呼吸动画，图到了淡入替换。
- ⚠️ **不能自动起播**（微信《常见拒绝情形》**3.5.2** 原文：「禁止视频、音乐、语音等多媒体的自动播放」）→ 音频就绪后自动跳 P3，但**停在待点的播放键上**，家长点一次才起播。睡前场景里这一下本来就要按（调音量、确认孩子躺好），不是体验损失；**不要为了少一次点击去绕这条，属于 2.5.19 绕开审核机制**。
- 取消 = 中断前端轮询并通知后端终止；已产生的成本计入日志但**额度返还**。
- **锁屏会中断生成中的轮询**（官方：进入后台后 5s 内未结束的网络请求会回调错误）→ `onHide` 停轮询、`onShow` 立即重拉 progress 并续上已收到的段落，**不能显示成失败态**。家长很可能在等的过程中关灯或锁屏，这条决定首跑体验。
- 失败态：插画小人 + 具体文案 + `[再试一次]`（同 requestId）+ `[换个说法]`（回 P1）。绝不给空白页。

## P3 故事播放页（核心）

```
┌──────────────────────────────┐
│ ←   小兔子第一次自己睡觉        │  ← 标题
│     给乐乐的第 5 个故事 · 5分钟 │  ← 副标题
│                              │
│  ╔══════════════════╗        │
│  ║   当前段绘本图      ║        │  ← 3:4，圆角，占 ~45% 屏
│  ╚══════════════════╝        │
│                              │
│  兔子轻轻躺下，被子软软的。      │  ← 上一句（灰）
│ ▶ 它闭上眼睛，数自己的耳朵。     │  ← 当前句（24px，橘色，加粗）
│  一、二、一、二… 耳朵数不完。    │  ← 下一句（灰）
│                              │
│  ────────●─────────  02:14/05:03 段 3/5
│  ⏮   ▶️/⏸   ⏭        0.8x ●1.0x 1.2x
│  ♡收藏   ⏱播完停   🔄再来一个   │
└──────────────────────────────┘
```

**逐句高亮**

- 只渲染当前段的 2-4 句（段 = 屏）；当前句由 `startMs ≤ now < endMs` 决定，前一后各带一句，形成视觉节奏。
- 当前句变 24px + 橘色 + 轻微上浮；切换用 200ms 过渡，不做逐字动画（性能 + 抖动）。
- 段自动翻页：当前句属于新段时，图片与文字整体上滑切换（一次 `setData`）。
- 横滑手动翻段 = 同时 `seek` 到该段首句 `startMs`；点击任意句子 = seek 到它并重播。
- 高亮数据缺失时（时间戳兜底路径）按估算时间走，视觉无差异。

**播放控制**

- 用 `wx.getBackgroundAudioManager()`（**全局唯一实例**，`title` **必填**），`title` = 故事标题、`coverImgUrl` = 首段图、`src` = 音频 URL。**熄屏与切后台继续播放**，锁屏有控制条——这是睡前场景的必需能力。前提：`app.json` 配 `requiredBackgroundModes: ["audio"]`，且**正式版需通过审核后生效**（体验版可直接生效，所以睡前全流程要在体验版真机验，别等上线）。
- ⚠️ **进入 P3 不自动 `play()`**（拒绝情形 **3.5.2**「禁止视频、音乐、语音等多媒体的自动播放」）→ 首屏是「大播放键 + 一句话文案」的待点态，点一次才起播。**区分两件事**：已播出的音频在熄屏/后台继续 = 允许；没有用户点击就让媒体开始播 = 禁止。段间翻页、点句重播、`onShow` 回前台，凡 `play()` 调用点都要能追溯到一次真实点击。
- 语速 0.8/1.0/1.2：改变语速需后端重新合成（时间戳随之变化），本地缓存当前篇已合成的各语速版本，命中秒切；未命中走一次合成（提示 `正在调整声音…`）。
- 定时：`播完停止`（默认且主推）/ 15 分钟 / 30 分钟。**官方限制**：切入后台后「不能通过调用 API 操纵音频的播放状态」→ 15/30 分钟档只在小程序在前台时生效，chip 上直接标 `（需亮屏）`，不要藏进说明里。到点走 `stop()` + 提示，不改系统亮度（权限拿不到）。
- 「再来一个」= 沿用同一输入与参数生成新故事（内容必须与上一篇不同，Prompt 带 `避免与上一标题/开头重复`），额度照常扣。
- 播完：停在最后一段，显示 `晚安，乐乐 🌙` + `[再来一个]` `[收藏]`，**不自动连播**。

**AIGC 标识**：副标题下方常驻小字 `内容由AI生成 · 故事与插图均为人工智能生成`。官方类目表要求「在 AI 生成内容显著位置进行标注，如：明确标注为'AI生成、人工智能生成'或同等含义字样」→ **确保「AI生成」四字原样出现**，不可折叠、不可被分享截图裁掉。

> 音频另有两层义务（《人工智能生成合成内容标识办法》第四条(二)、第五条）：显式标识可走「**在交互场景界面中添加显著提示标识**」这一支，即上面这行小字，**不必在 mp3 里插一句口水音**；但**文件元数据里的隐式标识是强制的、不给二选一**。将来若提供音频下载/导出，第四条末句要求文件内自带显式标识，那时必须把提示做进音频。详见 `docs/接口与数据.md` §3。

```
│  [收藏] [听过]                │  ← Segment
│  ─────────────────────       │
│  今日已用 1 / 3 次             │
│  设置                         │
│   默认音色  温柔姐姐        ›  │
│   背景音    雨声            ›  │
│   深色更暗   [●]              │

│  关于 · 内容说明（AI 生成）     │
└──────────────────────────────┘
```

**要点**

- 列表项 = 缩略图 + 标题 + 「第 N 个故事」+ 时长；点击进入 P3 直接可播（音频 URL 可能已回收 → 走「按已存文本重新合成」，用户无感）。
- 删除是软删（保留 30 天可恢复），收藏的不可被生命周期任务删除。
- 「设置」里的默认音色/背景音写回用户配置表，P1 直接读取，减少每晚点击。
- 空态：`还没有故事，去讲第一句吧 →` 直接跳 P1。

## 全局交互约定

| 场景 | 处理 |
|------|------|
| 弱网/超时 | 顶部细条提示 `网络不太好`，生成中保留已收到的段落，可继续等或取消 |
| 额度用尽 | P1 按钮置灰 + P4 显示 `明天再来`；不弹付费（首版无支付） |
| 内容被拦 | 文案只说「换一个说法」，**不透露命中了什么**（安全要求） |
| 登录失败 | 静默重试 1 次，仍失败则允许纯本地浏览最近列表，生成时再要求 |
| 键盘遮挡 | 输入框聚焦时页面上移，主按钮跟随可见 |
| 安全区 | 底部 `env(safe-area-inset-bottom)`，iPhone 播放条不被 home 横条压住 |
| 无障碍 | 播放按钮 `aria-label`；高亮句变化不播报（睡前无意义） |

## 文案禁词表（合规驱动，不是审美选择）

这些词会主动把产品往「拿不到证的类目」上靠，全部禁用。理由分别注在末尾。

| 类别 | ❌ 不用 | ✅ 改说 |
|------|--------|--------|
| 出版声称 | 绘本、故事书、电子书、出版物、读物、发行、上架、馆藏 | **AI 生成的睡前故事** |
| **音频/节目声称** | **听书、电台、FM、频道、节目、栏目、播音、连播、专辑** | **讲故事、朗读、AI 语音讲述** |
| 教育声称 | 课程、培训、老师、教学、作业、辅导 | 寓意、晚安、亲子共读 |
| 视频 | 动画、影片、剧集（首版无视频） | 插图、画面 |

**为什么「节目/电台/听书」这一组现在也进禁词表**（本轮核实新增）：微信类目表「文娱-电台」的适用范围原文含「电台/网络电台/FM/广播收听平台/**音频节目**等服务」，「文娱-有声读物」含「提供**版权读物的语音播报**等服务」，两者的资质（《信息网络传播视听节目许可证》等 2 选 1 / 4 选 1）**全部要求申请人具备法人资格**，个体工商户交不出，换民营公司也解不开视听证的「国有独资或控股」。**我们的抗辩点只剩文字层面**：讲的是单次 AI 生成的**原创**故事，不是「播别人的书」，也不是「一档节目」——所以简介、页面标题、类目申请说明里绝不能自己写出那组触发词。

⚠️ 「绘本插画风格」作为**美术风格描述词**在内部文档与设计稿里仍可用（那是风格，不是形态声称），但**不出现在用户可见文案**。

> 类目层面的根本缺口（类目表无任何语音合成子项）与两通开工前的电话见 `docs/MVP排期.md` §6.1、`docs/主体与证照准备.md` §8。
